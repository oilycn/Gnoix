## 📖 软件全景概览

**Gnoix** 是一款深度重塑 iOS 沙盒生态的集成式全能应用框架。它不仅将**全格式影视点播**、**全屏电视直播**与完整的 **Legado（开源阅读）双引擎** 融为一体，更独创性地在 App 内部原生整合了 **LiveContainer 应用分身运行容器** 与 **AutoSign 端内免电脑自动签名续签系统**。

无需越狱、无需常开电脑、摆脱服务器 502 宕机限制，一台 iPhone 即可实现日常娱乐、多开分身与侧载应用的全生命周期管理。

## ✨ 详细功能介绍

### 一、🎬 影音娱乐与流媒体（Media & Live TV）

1. **多源聚合影视点播**
   * **全源聚合与智能搜索**：内置自适应内容加载框架，支持一键切换内容源，支持多源同时搜索聚合与实时选源。
   * **播放记忆与续播**：自动记录每部剧集的观看历史、分集节点及精准到秒的播放进度。
   * **深度播放体验**：集成影院级定制播放器内核，支持倍速无级调整、画面比例拉伸、视频画中画（PiP）后台播放。
   * **个性化皮肤风格**：内置「影院沉浸」、「琥珀金光」等精美现代播放器控制层皮肤，可随时随心切换。

2. **全屏电视直播**
   * **格式兼容**：全面支持标准 `M3U`、`TXT` 直播源格式导入。
   * **智能分组与换台**：支持按央视、卫视、地方及特色专区智能分类；全屏播放时支持**从右侧屏幕边缘向左轻滑呼出专属切台抽屉**，换台丝滑顺畅。

3. **智能按需投屏（独家 AirPlay 防误触）**
   * **传统播放器通病**：大多数第三方播放器底层默认开启设备后台嗅探，当手机连入家庭 Wi-Fi 时，只要局域网内存在智能电视或盒子，iOS 系统便会频繁、突兀地在屏幕中间跳出“是否连接到【客厅电视】？”的打扰弹窗。
   * **Gnoix 独家优化**：采用**按需动态授权机制**，播放时默认保持完全静默；仅在您主动点击「无线投屏」图标时才拉起系统投屏选择列表，既保障随时投屏的大屏体验，又彻底消除不速之客般的弹窗困扰。

### 二、📚 开源小说阅读器（Legado 双引擎）

1. **本地离线阅读引擎**
   * 支持导入本地 `TXT`、`EPUB` 格式电子书。
   * 内置目录分卷分析算法，毫秒级快速提取小说章节目录。
   * 支持内容正则清洗净化规则，自动过滤不良广告与错乱排版。
   * 集成系统级原生 TTS 语音引擎，支持定时关闭与语速语调微调。

2. **远端阅读服务器 API 深度对接**
   * 原生兼容标准的开源阅读（Legado）服务端 API。
   * 支持多端云书架秒级同步，自动继承服务端的成千上万个精选书源。
   * 支持在线搜书、书源订阅管理与全网书籍章节发现。

### 三、📦 LiveContainer 应用分身运行容器

1. **免越狱应用多开**
   * 突破 iOS 个人账号 3 个桌面安装槽位的硬性限制，直接在 Gnoix 宿主沙盒内部动态加载运行第三方 `.ipa` 应用程序。
   * 采用无 JIT 运行技术，在未开启 JIT 权限的纯净系统环境下即可稳定启动主流应用与工具。

2. **无缝运行与生命周期交接**
   * 支持宿主主界面与容器应用之间的双向热交接（`livecontainer-relaunch`），应用数据独立存放在专属隔离目录，分身互不干扰。

3. **独家应用图标角标自动清零**
   * **痛点解决**：容器内分身应用（如即时通讯、社区类 App）在产生未读通知时，由于共享宿主进程，会导致红点数字直接遗留在手机桌面的 Gnoix 图标上，且普通方式无法消除。
   * **智能清理**：Gnoix 内置了前台状态侦测机制，每次从分身切换回主程序或打开主页时，系统自动执行静默角标归零（`Badge Count = 0`），并在设置中提供了手动一键清除按钮。

### 四、⚡ AutoSign 端内免电脑自动签名系统

**这是 Gnoix 最具技术突破性的核心模块，让 iPhone 首次彻底脱离电脑，实现全链路本地闭环签名与 7 天到期免重装自动续签。**

```
 ┌────────────────────────────────────────────────────────────────────────┐
 │                    Gnoix 端内自动续签闭环工作流                        │
 └───────────────────────────────────┬────────────────────────────────────┘
                                     │
      1. 本地生成硬件指纹             ▼
   ┌──────────────────────────────────────────────────────────────────────┐
   │ 📱 On-Device Anisette (内置 ARM64 Unicorn 虚拟机执行 libCoreADI.so)  │
   │    无需联网，真机本地生成标准合规硬件指纹 (彻底告别 502 宕机)        │
   └─────────────────────────────────┬────────────────────────────────────┘
                                     │
      2. 苹果官方开发者通道鉴权       ▼
   ┌──────────────────────────────────────────────────────────────────────┐
   │ 🍎 AppleAuthService (GrandSlam 2FA 认证)                             │
   │    直接获取 1 年长效官方 Xcode 凭证 (com.apple.gs.xcode.auth)        │
   │    向苹果开发者服务申请最新合法的 7 天官方 Provisioning Profile      │
   └─────────────────────────────────┬────────────────────────────────────┘
                                     │
      3. 系统底层隧道免重签注入       ▼
   ┌──────────────────────────────────────────────────────────────────────┐
   │ 🔒 iOS 17 RemotePairing RSD 隧道 (CDTunnel + 本地回环 VPN)           │
   │    直连 iOS 底层 misagent 服务，直接把最新描述文件注入系统信任库    │
   │    🎉 授权自动顺延 7 天，原应用无需重装、无需重签，到期绝不闪退！    │
   └──────────────────────────────────────────────────────────────────────┘
```

1. **纯真机 On-Device 独立 Anisette（告别 502）**
   * **技术突破**：在 iOS 内部嵌入了 ARM64 Unicorn CPU 模拟器与 Apple 官方 `libCoreADI.so` 核心库。
   * **本地生成**：在真机沙盒内直接虚拟化执行 ADI 计算，本地与苹果官方注册合法 `adi.pb` 会话凭据。
   * **优势**：**不需要搭建或连接任何公共/远程 Anisette 服务器**，在手机完全断开互联网的极端环境下依然能离线生成硬件指纹，彻底终结了公网服务器因被风控或宕机频繁报错 `502 Bad Gateway` 的顽疾。

2. **AppleAuthService 官方开发者标准通道**
   * 支持通过 2FA 两步验证登录您的个人 Apple ID。
   * 模拟官方 Xcode 客户端行为，一次登录即可换取长达 **1 年有效期的官方开发者会话令牌（`com.apple.gs.xcode.auth`）**，后续签名续期全程静默免验证码。
   * 实时同步苹果开发者平台当前账号每周 10 个已注册 App ID 的配额与到期释放倒计时。

3. **iOS 17+ 原生 RemotePairing 隧道免重签注入（核心防闪退）**
   * **为什么 7 天到期不会闪退？**
     苹果个人开发证书的公钥在 1 年内都是合法的，导致 App 7 天闪退的唯一原因是**描述文件（Profile）的 7 天期限过期**。
   * **Gnoix 怎么做**：
     通过本地回环 VPN（utun）与 `CDTunnel` 握手，直接接入真机系统的底层安全通道 `misagent` 服务，**原地把苹果官方新签发的 7 天描述文件注入系统信任库**。
   * **结果**：**无需重新下载、无需重新打包、无需重新签名 Mach-O，手机自己就把自己的寿命顺延了 7 天，永远不会闪退**。

4. **第三方 IPA 代码签名与桌面直装**
   * 内置高性能 C++ ZSign 原生签名引擎，自动清洗 PlugIns/Extensions 规避配额冲突。
   * 集成真机本地 HTTP 28080 与 HTTPS 28443 ATS 兼容安装服务，支持将签名后的 IPA 通过 `installation_proxy` 免电脑一键静默安装至 iOS 桌面。

5. **iOS 快捷指令（Shortcuts）自动化**
   * 开放 `gnoix://autosign/renew` 标准 URL Scheme 与原生快捷指令意图。
   * 配合 iOS 自带的「快捷指令」App 设置夜间每日自动化定时任务，实现**手机放在床头充电时自动完成所有应用续签**，彻底解放双手。

## 📲 安装与首次配置指南

### 第一步：安装 Gnoix 宿主程序
由于本项目目前提供编译打包好的纯净未签名安装包，您可以通过以下任意主流方式将 `Gnoix.ipa` 安装到您的 iPhone：
* **TrollStore（巨魔商店，推荐）**：iOS 14.0 - 16.6.1 巨魔设备直接导入，享受永久免签名与最高系统权限。
* **个人 Apple ID 签名安装（推荐）**：
  * **Xcode**：在 Mac 上打开项目工程或使用 `devicectl` 签名安装。
  * **Sideloadly / iLoader / 爱思助手**：导入 `Gnoix.ipa`，输入您的 Apple ID 进行签名并安装到真机。

### 第二步：导出并导入设备配对凭证（仅需配置一次）
要启用 iOS 17+ 的本地回环免电脑静默注入，需要为 App 授权真机配对信任：
1. 使用电脑通过数据线连接一次 iPhone。
2. 使用 SideStore 官方配对工具、Jitterbug 或爱思助手，导出本机的设备配对文件（文件名通常为 `你的UDID.mobiledevicepairing` 或 `.plist`）。
3. 通过隔空投送（AirDrop）、微信文件传输或微云将该文件发送至手机。
4. 打开 Gnoix，进入 `设置 -> 自动签名 -> 设备配对文件`，点击导入该文件即可。

### 第三步：登录 Apple ID 并开启端内独立续签
1. 进入 `自动签名` 界面，点击「登录 Apple ID」，输入账号密码并提交弹出的 6 位双重验证码。
2. 在 Anisette 选项中，选择 **「端内独立模式 (On-Device)」**（推荐，零外部依赖）。
3. 此时点击「一键续签」，系统将自动完成：
   `本地生成指纹 -> 申请7天描述文件 -> RSD隧道连接 -> misagent注入`。
4. 看到提示 `🎉 描述文件成功通过 RSD misagent 注入 iOS 系统` 即代表全流程配置成功！

## ❓ 常见问题深度解答（FAQ）

#### Q1：通过注入描述文件续签，到期后软件到底会不会闪退？
**答：只要在 7 天内成功刷新注入，绝对不会闪退。**
iOS 内核在校验应用启动时遵循双层逻辑：
1. Mach-O 代码与证书是否匹配？（免费证书有效期为 1 年，一年内只要未吊销就始终合法有效）；
2. 系统凭证库中该 Bundle ID 的描述文件是否在有效期内？
Gnoix 通过底层的 `misagent` 隧道，直接向 iOS 系统证书库替换了由苹果官方服务器签发、有效期顺延 7 天的新描述文件。系统判定授权处于有效期内，直接放行，这与 SideStore / AltStore 的官方刷新原理完全一致。

#### Q2：为什么不用第三方的公网 Anisette 服务器，而推荐端内模式？
**答：彻底告别网络不可控与 502 错误。**
公网公共 Anisette 服务器（如 SideStore 官方节点）经常由于全球大量用户并发请求触发苹果 IP 风控，导致频繁返回 `502 Bad Gateway`。Gnoix 借助真机内置的虚拟化环境直接执行底层指令集，把硬件指纹的生成完全收归手机本地，不走任何外网中间服务器，速度更快且永远不会宕机。

#### Q3：如果最开始是用爱思助手或 Sideloadly 签名的，后续能在 App 里自动续签吗？
**答：完全可以。**
在 iOS 系统内核眼中，不存在所谓的“爱思特征”或“Xcode 特征”，所有工具生成的都是苹果标准代码签名。只要在签名时保持应用的原始包名（Bundle Identifier）一致，且中途不要随意在不同电脑上点击“吊销云端所有证书”，Gnoix 都能无缝接管并完成原地刷新。
